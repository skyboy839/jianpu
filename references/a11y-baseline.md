# 可访问性基线 / Accessibility Baseline

## 地位

本文件是**前置基线**，不是可选章节。任何界面任务默认引用；行业 profile（医疗、政务、教育、HMI 等）只做加法，不改基线。

## 目标级别声明

`design-spec.md` 必须声明目标 WCAG 级别：
- `AA`（默认）
- `AAA`（医疗、教育、政务推荐）
- `A`（仅历史遗留，需附理由）

## 阶段分离（引用）

**阶段的定义**（direction-proposal / design-spec / 最终落地版本）见 `three-directions-gate.md` 的「阶段分离」小节——本文件不重复阶段划分。

本文件只定义各阶段的 **a11y 义务**：

| 阶段 | 本阶段 a11y 义务 |
|---|---|
| direction-proposal | 无（direction-proposal 只出 1 套 light；a11y 完整义务不在本阶段承担） |
| design-spec | light/dark 成对色板 + 对比度自动检查 + 触控目标规格 |
| 最终落地版本 | 完整 a11y 检查（键盘、焦点、动效、语义树） |

**加载时机**：本文件在 **design-spec 阶段起**加载（见 SKILL.md 的「a11y-baseline 加载时机」段落）。存量缺陷修复不产生新 design-spec 时，按需加载相关小节（如对比度）做校验。

## 基线清单

### 对比度

- 正文 ≥ 4.5:1（AA）/ 7:1（AAA）。
- 大字与 UI 组件 ≥ 3:1（AA）/ 4.5:1（AAA）。
- 所有 token 色对**自动检查**——在 `design-spec.md.colors.contrast_checked` 显式断言，不做隐式假设。

### 键盘

- 所有交互元素可 Tab 到达。
- 焦点环可见（≥2px，对比 ≥3:1）。
- 键盘操作顺序 = 视觉顺序。
- 无键盘陷阱（Tab 出不去的弹窗为红线）。

### 动效

- 尊重 `prefers-reduced-motion` / 系统等价设置（桌面、移动）。
- 关闭动效后信息不丢失（不能靠动画传达状态）。
- 闪烁频率 ≤3 Hz。

### 暗色模式（a11y 子模块）

- 暗色不是审美，是对光敏感用户的适配。
- design-spec 强制**成对**产出 light/dark 两套色板。
- 暗色对比度独立检查——不可从浅色简单反转。

### 图像与图标

- 信息性图像必须有替代文本。
- 纯装饰图标加 `aria-hidden` / `AccessibilityHidden`。
- 图标色不单独承载信息（配文字或形状差异）。

### 隐私与同意 UI

- 同意弹窗可键盘操作、可读屏朗读。
- 数据可见性层级明确（公开 / 内部 / 敏感 / 极敏感）。
- 脱敏展示作为默认（如卡号只显示尾 4 位）。

### 移动触控

- 触控目标 ≥ 44×44 CSS px（≥ 48px 用于工业/HMI）。
- 相邻触控目标间距 ≥ 8px。

## 硬红线

以下任一即视为**评审 Fix 级别**，无论评分：
- 任何文本对比 < 3:1。
- 焦点环不可见。
- 无键盘操作路径。
- 闪烁 >3 Hz。
- 信息仅靠颜色传达。

## 行业扩展

各行业 profile 通过 `extends: a11y-baseline` 声明，只新增约束。例如医疗 profile 增加"误操作防护"和"色盲安全色板"，但对比度基线仍由本文件定义。

## 与 static-deliverable 的关系

static 交付下 a11y 检查的可核对性见 `static-deliverable.md` 的「与 a11y-baseline 的关系」小节——能核对的（如对比度）必须核对，不能核对的（如键盘、动效）标注"待运行时验证"。
